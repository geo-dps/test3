# 🔥 Огонёк — Telegram Business Bot

Это обычный Telegram Bot API бот. Никаких `API_ID`, `API_HASH`, Telethon, session-файлов и авторизации пользовательского аккаунта нет.

Бот работает через **Telegram Business Mode**: владелец Telegram Business подключает бота к своему аккаунту, а бот получает Business Message Updates и может отвечать от имени подключённого бизнес-аккаунта при наличии соответствующего права.

## Возможности

- 🔥 серия переписки по календарным дням;
- 👤 выбор контакта;
- 📨 приглашение на огонёк;
- уведомление после каждого засчитанного дня;
- напоминание вечером, если день ещё не закрыт;
- статус `.`, красивое меню;
- SQLite;
- готово для Railway/GitHub;
- без входа в пользовательский аккаунт.

### Правило

День засчитывается только если **оба** человека отправили хотя бы одно сообщение друг другу в течение этого календарного дня.

Пример:

28 августа — оба написали → 🔥 1 день
29 августа — оба написали → 🔥 2 дня
30 августа — оба написали → 🔥 3 дня
31 августа — переписки нет → серия прерывается

Новый день после пропуска начинает новую серию с 1.

## Важно про Telegram Business

В @BotFather для бота нужно включить Business Mode / Secretary Mode и дать боту права на обработку сообщений.

Telegram передаёт боту `business_connection_id`, а сообщения из управляемых чатов приходят как Business Messages. Для отправки сообщения от имени бизнес-аккаунта используется тот же `business_connection_id`.

Telegram ограничивает исходящие сообщения через Business Connection: бот может отвечать в подходящих управляемых приватных чатах, в частности когда собеседник недавно писал бизнес-аккаунту. Поэтому приглашение может быть отклонено самим Telegram, если конкретный чат недоступен для ответа.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

В `.env` нужен только:

```env
BOT_TOKEN=123456:ABC...
DB_PATH=/data/streak.db
TIMEZONE=Europe/Berlin
REMINDER_HOUR=20
REMINDER_MINUTE=0
```

Никаких API_ID/API_HASH и никаких Telegram user sessions.

## Запуск

```bash
python -m app.main
```

## Railway + GitHub

1. Создайте GitHub repository.
2. Загрузите файлы проекта.
3. В Railway создайте новый Project.
4. Выберите **Deploy from GitHub Repo**.
5. Выберите этот repository.
6. Добавьте Variables:
   - `BOT_TOKEN`
   - `TIMEZONE`
   - `REMINDER_HOUR`
   - `REMINDER_MINUTE`
   - `DB_PATH=/data/streak.db`
7. Добавьте Railway Volume и примонтируйте его к `/data`.
8. Deploy.

Polling специально выбран здесь, поэтому отдельный публичный webhook URL не нужен.

## Первое подключение

1. Откройте своего бота.
2. Нажмите `/start`.
3. В @BotFather включите Business Mode для бота.
4. В Telegram Business подключите бота к своему аккаунту.
5. Разрешите боту управлять нужными чатами и отвечать на сообщения.
6. В диалоге с ботом нажмите `👤 Выбрать контакт`.
7. Выберите человека.
8. Нажмите `📨 Пригласить на огонёк`.
9. После начала переписки бот будет считать календарные дни.

## Хранение данных

SQLite используется для простого запуска. На Railway обязательно используйте Volume `/data`, иначе база может быть потеряна при пересоздании контейнера.

## Ограничения Telegram

Бот не может самовольно писать любому пользователю в Telegram. Приглашение отправляется через Business Connection от имени бизнес-аккаунта и подчиняется правам подключения и ограничениям Telegram.

Также бот видит только те бизнес-чаты, которые были переданы ему через настройки Business Connection.
